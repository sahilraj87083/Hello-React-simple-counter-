# 🔢 React Counter App — Value Increment & Decrement

A simple and beginner-friendly React project demonstrating state management using the **useState hook**.  
The app displays a numerical value that can be increased or decreased using buttons — with **upper and lower limits applied**.

---

## 🚀 Features
- Displays a dynamic value on the screen
- Increase value using an **Increment button**
- Decrease value using a **Decrement button**
- Prevents value from going **below 0**
- Prevents value from going **above 20**
- Fully powered by the **useState hook**

---

## What You Learn from This Project

- How to use useState in React
- Updating state on button click
- Applying logic inside state setter functions
- Implementing value boundaries (min and max)
